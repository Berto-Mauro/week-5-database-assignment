# Week 5 Database Assignment

## Database Indexing and Optimization

This project contains my SQL solutions for the Week 5 Database Assignment. The assignment focuses on database indexing, user accounts, privileges, security, and SQL commands in MySQL.

## Assignment Questions

The `answers.sql` file contains solutions for four questions:

1. Drop the `IdxPhone` index from the `customers` table.
2. Create a MySQL user named `bob` restricted to `localhost`.
3. Grant the `INSERT` privilege to `bob` on the `salesDB` database.
4. Change the password for the `bob` user.

## Files

* `answers.sql` - Contains all SQL queries for the assignment.
* `README.md` - Provides a short description of the project.

## Requirements

To run the SQL queries, you need:

* MySQL Server
* MySQL Workbench or another MySQL-compatible SQL editor
* Appropriate database privileges for creating users and granting permissions.

## How to Run

1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Open the `answers.sql` file.
4. Run the SQL queries.
5. Check the results and confirm that each command executes successfully.

## Learning Outcomes

Through this assignment, I practiced:

* Managing database indexes.
* Creating MySQL users.
* Granting database privileges.
* Changing user passwords.
* Applying basic database security and access control.
